I rebuilt NHHS Consulting's website and moved its publishing setup from Wix to
Hugo. The site presents the consultancy's services, people and articles.
Contributors edit content in Decap CMS, and GitHub Actions publishes changes to
Cloudflare Pages.

![The public NHHS Consulting homepage](featured.png)

## Publishing after the handover

The work includes an operating guide for routine updates and the next person
responsible for the site. Content lives separately from the page templates, so
an article or team profile can be updated without changing the design.

My work covered the rebuild, the publishing workflow and the operating
documentation, using AI-assisted development.

## Monitoring after launch

NC-vakt checks DNS and public pages. It distinguishes a failed check from a
check that could not be completed, and limits repeated alerts.
